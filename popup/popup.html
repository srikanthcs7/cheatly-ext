How to Use

  1. Choose API mode in Settings (QuizSolve API or own key)
  2. If using own key, enter it and select model
  3. Press Ctrl+Shift+U to activate on any page
  4. Double-click on any question to get the answer
  5. Shift+Double-click for answer with explanation

Supported Question Types

  • Multiple Choice (MCQ)
  • Multiple Select
  • True / False
  • Fill in the Blank
  • Matching
  • Short Answer
  • Essay Questions
  • Image/Diagram-based Questions

Vision Support

  • Auto-detects images, diagrams, charts in questions
  • Sends visuals to AI for accurate answers
  • Smart Switch auto-upgrades model for image questions
  • Works with screenshots, graphs, code snippets

Stealth Features

  • No visible UI on the page
  • Off by default — activate only when needed
  • Double-click behaves normally
  • No branding or overlays

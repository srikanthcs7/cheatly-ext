How to Use

  1. Choose API mode in Settings (Free or Pro)
  2. Press Ctrl+Shift+U to activate on any page
  3. Double-click on any question to get the answer
  4. Shift+Double-click for answer with explanation
  5. Ctrl+Shift+D Draw region to capture & solve
  6. Ctrl+Shift+S Snap full screen to solve

Double-click Not Working?

On some websites, double-click may not work for certain questions. Try switching the answer mode:

  • Highlight — subtly highlights the correct option without interacting with the page
  • Clipboard — copies the answer to your clipboard silently, no page interaction at all

You can change the answer mode in Settings → Answer Mode.

How to Use

  1. Enter your API key in Settings
  2. Choose your AI model in Models
  3. Press Ctrl+Shift+U to activate on any page
  4. Double-click on any question to get the answer

Supported Question Types

  • Multiple Choice (MCQ)
  • Multiple Select
  • True / False
  • Fill in the Blank
  • Matching
  • Short Answer
  • Essay Questions
  • Image/Diagram-based Questions

Vision Support

  • Auto-detects images, diagrams, charts in questions
  • Sends visuals to AI for accurate answers
  • Smart Switch auto-upgrades model for image questions
  • Works with screenshots, graphs, code snippets

Stealth Features
